# Environment Builder — Practical Specification

> The Environment Builder transforms any project directory into an engineering environment with a single command: `ath env init`.

---

## 1. Input — What Athena Detects

| Signal | File / Command | Detection Method |
|--------|---------------|------------------|
| **Rust** | `Cargo.toml` | File exists |
| **Python** | `pyproject.toml`, `setup.py`, `requirements.txt` | File exists (ordered) |
| **Node** | `package.json`, `package-lock.json`, `yarn.lock` | File exists |
| **Go** | `go.mod` | File exists |
| **C/C++** | `CMakeLists.txt`, `Makefile`, `meson.build` | File exists |
| **Docker** | `Dockerfile`, `docker-compose.yml` | File exists |
| **Devcontainer** | `.devcontainer/devcontainer.json` | File exists |
| **Nix** | `shell.nix`, `flake.nix`, `default.nix` | File exists |
| **asdf** | `.tool-versions` | File exists |
| **Git** | `.git/` | Directory exists |
| **CI** | `.github/`, `.gitlab-ci.yml`, `Jenkinsfile` | File/dir exists |
| **Editor** | `.vscode/`, `.idea/`, `.vimrc` | File/dir exists |

Detection is **cheap**: stat() calls, no parsing. Runs in < 10ms.

### Runtime Recommendation Logic

```rust
fn recommend_runtime(profile: &EnvironmentProfile) -> RuntimeRecommendation {
    // 1. Prefer local over cloud (always)
    // 2. Prefer already-running over cold-start (health check)
    // 3. Prefer fastest inference for available model
    // 4. Filter by: model_format == runtime_supported_formats
    
    match (&profile.models, &profile.runtimes) {
        (models, _) if models.iter().any(|m| m.path.ends_with(".gguf")) && runtimes.llama_cpp => 
            RuntimeRecommendation::new(LlamaCpp, models.first()),
        (_, runtimes) if runtimes.ollama_available =>
            RuntimeRecommendation::new(Ollama, profile.runtimes.ollama_models.first()),
        (_, runtimes) if runtimes.openai_key_present =>
            RuntimeRecommendation::new(OpenAI, None),
        _ => RuntimeRecommendation::none("No compatible runtime + model pair found."),
    }
}
```

## 4. Cache — What Persists and When

| Cache | Key | Lifetime | Invalidated When |
|-------|-----|----------|-----------------|
| Project fingerprint | sha256 of (project_files + tool versions) | Indefinite | Any project file changes |
| Knowledge Pack | `<language>-<version>.yaml` | 7 days | Detected tool version changes |
| Repo summary | `athena/repo.json` | Indefinite | Git HEAD changes |
| Tool inventory | `athena/tools.json` | 1 hour (fast) | — |
| Optimization profile | `athena/optimization.yaml` | 30 days | Hardware changes |
| Experiment history | `.state/experiments/*.json` | Indefinite | — |

**Cache miss cost**: `ath env init` on cached project: ~200ms. Fresh: ~2-8s (depends on knowledge generation).

## 6. Architecture Corrections (from ARCH-0001 review)

### MemoryProvider trait (not a framework)

```rust
trait MemoryProvider: Send + Sync {
    fn id(&self) -> &str;
    fn store(&self, namespace: &str, key: &str, value: &str) -> Result<(), String>;
    fn retrieve(&self, namespace: &str, query: &str, limit: usize) -> Result<Vec<MemoryRecord>, String>;
    fn compact(&self, namespace: &str) -> Result<(), String>;
}

// Implementations (not built-in):
// - Mem0Provider (Apache 2.0, hybrid search)
// - LightRAGProvider (lightweight, local-friendly)
// - SQLiteProvider (no dependencies, always available)
// - FilesystemProvider (JSON files, no external deps)
```

### RuntimeCapabilities as data (not trait methods)

```rust
pub struct RuntimeCapabilities {
    pub streaming: bool,
    pub vision: bool,
    pub embeddings: bool,
    pub tool_calling: bool,
    pub structured_output: bool,
    pub reasoning_tokens: bool,
    pub images: bool,
    pub mcp: bool,
    pub offline: bool,
    pub context_window: usize,
    pub kv_cache_types: Vec<String>,  // ["q8_0", "q4_0", "f16"]
    pub max_parallelism: usize,
}
```

The **RuntimeRegistry's scheduler** decides which runtime to use. Runtimes only report their capabilities. Never decide.

### MCP as capability transport (not a runtime or provider)

```
Runtime
  │
  ▼
MCP Bridge (transport layer)
  │
  ├── Tools (execute code, run debugger, search web)
  ├── Resources (file contents, API responses, database queries)
  └── Prompts (reusable templates for consistent AI inputs)
```

MCP is how Athena's tools connect to the environment. Not how Athena runs inference.

### Optimization by objectives (not parameters)

```rust
pub enum OptimizationObjective {
    MaximumCapability,   // Highest benchmark scores, slowest
    MaximumThroughput,   // Fastest token generation
    MinimumLatency,       // Lowest TTFT
    MinimumVRAM,         // Fit in smallest GPU
    OfflineOnly,         // No internet required
    BatteryMode,         // Power-efficient
    Coding,              // Optimized for code generation
    Research,            // Optimized for analysis tasks
}

// The optimizer maps objective → parameters:
fn optimize(objective: OptimizationObjective, hw: &HardwareInfo) -> Configuration;
// Not: user selects context, threads, batch, kv, flash separately.
```

## 7. Success Criterion

The first milestone:

```
git clone <any repository>
cd <repository>
ath env init          # < 10 seconds, no user questions
ath run "Where is the authentication implemented?"
  → Valid answer using only local resources
```

Everything else (memory, optimization, agent loops) amplifies this.

Build this first. Measure it. Then iterate.
