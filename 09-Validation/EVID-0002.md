# EVID-0002 — Evidence: Runtime Spike

> **Authority:** Level 7 (Research)
> **Status:** Complete
> **Confidence:** 0.85

---

## Claim

The Athenas Runtime pipeline (`ath run`) can successfully:
1. Discover and load a local GGUF model
2. Spawn `llama-server` as a managed subprocess
3. Execute a natural language prompt
4. Measure TTFT (Time to First Token) with sub-100ms precision
5. Measure generation throughput (tokens/second)
6. Output results in both human-readable and structured JSON formats
7. Cleanly shut down the server process

## Evidence

### Successful Runs (2026-07-16)

| Run | Prompt | TTFT | Tokens/sec | Tokens | Status |
|-----|--------|------|------------|--------|--------|
| 1 | "Say hello in Spanish and introduce yourself briefly" | **70.1 ms** | **45.7** | 47 | ✅ Complete |
| 2 | "Reply with just the word: Hello" | **74.3 ms** | **53.5** | 5 | ✅ Complete |

### Verified Pipeline Stages

| Stage | Status | Details |
|-------|--------|---------|
| Model discovery | ✅ | `--model` path + auto-detection in `$HOME/models/` |
| Server spawn | ✅ | `llama-server` subprocess with proper args |
| Server reachable | ✅ | HTTP health check on configurable port |
| Model loaded | ✅ | Polls `/completion` until not 503 (async loading) |
| Inference | ✅ | POST `/completion` with JSON body |
| Timing (TTFT) | ✅ | `timings.prompt_ms` from llama-server response |
| Timing (throughput) | ✅ | Computed from `timings.predicted_n / predicted_ms` |
| Structured output | ✅ | `--json` flag produces valid JSON |
| Clean shutdown | ✅ | Server killed via `Drop` impl (panic-safe) |
| Error handling | ✅ | HTTP 503 → retry, HTTP 4xx/5xx → descriptive error |

## Confidence Justification

| Factor | Score | Notes |
|--------|-------|-------|
| Reproducibility | 0.90 | Multiple runs produce consistent results (70-74ms TTFT) |
| Measurement accuracy | 0.85 | TTFT from llama-server timings (not wall clock); some overhead from HTTP |
| Coverage | 0.80 | Only one model tested (Qwen3.5-4B), CPU-only |
| Error handling | 0.85 | 503 retry works; no Ctrl-C handler tested |

**Overall confidence: 0.85** — The pipeline is verified to work end-to-end with one model. Further testing across models, hardware, and edge cases will increase confidence.

## Conditions

- All measurements performed on CPU (no GPU offloading)
- Model: Qwen3.5-4B, Q4_K_M quantization, 2.9 GB
- Context window limited to 2048 for spike
- TTFT measured from llama-server's internal timings, not wall clock
- Background system load not measured (may affect results)
